# EchoBridge AI

EchoBridge AI is an accessibility-focused project designed to help deaf and speech-impaired individuals communicate more easily with hearing people.

## Problem Statement
Communication barriers can make it difficult for people with hearing or speech impairments to communicate in hospitals, banks, and police stations.

## Proposed Solution
EchoBridge AI aims to provide a simple, user-friendly interface to support communication through sign-language-related gestures and text messages.

## Current Prototype
- React-based web interface
- Gesture-to-message mapping
- Basic communication messages
- Further integration and testing in progress

## Technologies Used
- HTML
- CSS
- JavaScript
- React
- Vite
